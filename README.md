# 📧 Hệ thống Phân loại Email Spam Trực tuyến
Ứng dụng phân loại email rác sử dụng mô hình Cây Quyết Định (Decision Tree) được phát triển và tối ưu để chạy trực tiếp trên Streamlit Community Cloud.

## 🛠️ Cài đặt cục bộ (Tùy chọn)
Nếu muốn chạy thử nghiệm ứng dụng này tại máy tính cá nhân của bạn:
1. Tải kho lưu trữ này về máy tính.
2. Cài đặt các thư viện cần thiết:
```bash
pip install -r requirements.txt
```
3. Chạy ứng dụng:
```bash
streamlit run app.py
